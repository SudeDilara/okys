# OKYS - Kütüphane Yönetim Sistemi

Nesne Yönelimli Programlama (OOP) dersi için geliştirilmiş Java kütüphane otomasyon projesidir.

## Proje İçeriği
* *src/*: Java kaynak kodları (Kitap, KitapKopyasi, Kullanici, Odunckaydi)
* *doc/*: Tasarım diyagramları ve dokümanlar

## Kullanılan Teknolojiler
* Java
* Draw.io
